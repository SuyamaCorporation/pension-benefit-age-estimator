# 年金受給額 年齢別シミュレーター

加入年数・平均年収・受給開始年齢（60〜75歳）を入力し、老齢基礎年金＋厚生年金の概算受給額を計算します。

## 機能

- 老齢基礎年金（2024年度満額 816,000円/年ベース）＋厚生年金（報酬比例部分）の概算計算
- 繰上受給（60〜64歳・0.4%/月減額）と繰下受給（66〜75歳・0.7%/月増額）の全パターン表示
- 対65歳受給との損益分岐点計算
- 月額・年額の一覧テーブル
- 年額棒グラフ比較（赤=繰上・青=標準65歳・緑=繰下）

## 技術仕様

- 静的SPA（単一 index.html）
- Tailwind CSS CDN
- XSS対策: ユーザー入力は parseFloat で数値変換
- localStorage 不使用
